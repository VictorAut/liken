---
title: API Reference
---

[`liken`](./liken.md): main entrypoint.

[`liken.preprocessors`](./preprocessors.md): preprocessors, reserved for use when defining pipelines with [`lk.pipeline`](./liken.md#liken.pipeline), or it's related accessors, [`lk.Pipeline.step`](./liken.md#liken.Pipeline.step) and [`lk.col`](./liken.md#liken.col).

[`liken.custom`](./custom.md): registration function for custom dedupers.

[`liken.datasets`](./datasets.md): handy synthetic datasets for experimentation.
